== AuthService

* `sendDiscoveryEmail(SendDiscoveryEmailRequest request)` sends a Stytch B2B
  discovery Email Magic Link through
  `/v1/b2b/magic_links/email/discovery/send`.
* `SendDiscoveryEmailRequest` supports `emailAddress`,
  `discoveryRedirectUrl`, `pkceCodeChallenge`, `loginTemplateId`, `locale`, and
  `discoveryExpirationMinutes`.
* `SendDiscoveryEmailResponse` exposes the Stytch `requestId` and `statusCode`.

== InvitationService

* `sendInviteEmail(SendInviteEmailRequest request)` sends a Stytch B2B invite
  Email Magic Link through `/v1/b2b/magic_links/email/invite`.
* `SendInviteEmailRequest` supports `organizationId`, `emailAddress`,
  `inviteRedirectUrl`, `invitedByMemberId`, `name`, metadata, template, locale,
  roles, and `inviteExpirationMinutes`.
* `SendInviteEmailResponse` exposes the Stytch `requestId`, `memberId`, raw
  `member`, raw `organization`, and `statusCode`.
